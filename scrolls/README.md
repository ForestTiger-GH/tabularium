# Scrolls

`scrolls/` contains source-faithful, AI-readable primary publications and representations, as well as documented bridges to canonical high-volume primary datasets.

Selected untouched publisher files belong in [`originals/`](../originals/). A source already suitable for AI reading, such as a publisher HTML page, can be retained here directly without an additional original-file copy. A source series stored exclusively under `originals/` does not require a scroll conversion.

## Route

Route by country first unless an explicitly documented cross-country route applies.

- [`russia/`](russia/) — Russian public-source corpus.
- [`world/`](world/) — non-Russian and international publications routed by stable corporate source class or explicitly documented source institution; corporate reporting-entity jurisdiction is preserved in artifact names.

Selected source-extracted observations belong in [`flakes/`](../flakes/). Registries, repository tooling, research material, derived calculations, and analytical work do not belong in this directory.
