# Trading Results

Preserved HTML materials documenting recurring SPB Exchange trading-results releases.

Frequency: monthly; annual summary releases also occur.

## Provenance

Use official SPB Exchange publications where they remain available. For some historical periods, original official source pages are no longer publicly accessible; the surviving record may therefore be a third-party reprint or report reproducing figures released by SPB Exchange.

A third-party file is a preservation proxy, not a primary-source original. Preserve its actual publisher and provenance and do not silently attribute the file itself to SPB Exchange.
