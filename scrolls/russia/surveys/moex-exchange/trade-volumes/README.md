# Trading Volumes

Native XLSX historical trading-volume data published by Moscow Exchange.

## Update model

This is a cumulative historical dataset rather than a sequence of independent single-period issues. An update may replace the current workbook or appear under a new filename while retaining earlier historical observations.

Treat each workbook as a source-published version of the cumulative dataset. Preserve workbook content and structure unchanged; do not append, normalize, or reconstruct observations outside the source.

Source: official Moscow Exchange website.
