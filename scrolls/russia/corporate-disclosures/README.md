# Corporate Disclosures

Primary machine-readable corporate disclosures published by Russian corporate entities and groups, plus documented bridges to canonical regulatory reporting datasets for banks.

## Route

- [financial-reporting/](financial-reporting/) — IFRS, Russian Accounting Standards reporting, and Bank of Russia regulatory bank-reporting bridges.
- [annual-reports/](annual-reports/) — annual reports.
- [issuer-reports/](issuer-reports/) — periodic issuer reports.
- [strategies/](strategies/) — standalone corporate strategy, development-plan, guidance, outlook, and forecast publications grouped by publication year.

Store each source document as a complete source-faithful representation according to the repository rules. Keep distinct publication classes in their documented routes. A document already stored as an annual report, issuer report, or financial-reporting artifact is not duplicated in `strategies/` merely because it contains strategic targets or forward-looking statements. Remote bridge routes do not mirror high-volume source datasets unless the repository contract is explicitly changed.
