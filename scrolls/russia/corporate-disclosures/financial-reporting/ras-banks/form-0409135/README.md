# Form 0409135

Bank of Russia form 0409135: Information on Mandatory Ratios and Other Performance Indicators of a Credit Institution.

This directory contains a remote-source bridge rather than a mirrored monthly dataset.

Start from the institution reporting index for availability. For structured access, use the CreditOrgInfo form and metadata methods. Use the bulk DBF publication and date-effective format description when required.

Canonical bulk publication:
https://www.cbr.ru/banking_sector/otchetnost-kreditnykh-organizaciy/
