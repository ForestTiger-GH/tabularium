# McKinsey

Public publications released by McKinsey & Company that are intentionally admitted to Tabularium as source objects of that publisher.

This is a publisher-based route. Add stable publication-series subdirectories only when actual admitted publications require them.

Preserve the publication title or series, edition or date, version, source format, and provenance. Analytical conclusions published by McKinsey remain source content of the preserved publication; cited external data and claims do not become McKinsey-origin source observations and must retain their original provenance.
