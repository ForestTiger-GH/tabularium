# Stanford

Public-source publications released by Stanford University or a clearly identified Stanford unit that are intentionally admitted to Tabularium as source objects.

This is a publisher-based route. Add stable publication-series subdirectories only when actual admitted publications require them.

Preserve the actual publisher or unit, publication title or series, edition or date, version, source format, and provenance. A Stanford publication is primary evidence for what Stanford published; cited external datasets and third-party claims retain their own provenance and must not be silently promoted to Stanford-origin observations.
