# Social and Economic Situation of the Russian Federation's Constituent Entities

Original publisher archives for Rosstat's `Социально-экономическое положение субъектов Российской Федерации` statistical publication series.

## Route

Preserve each official release as its **untouched distribution archive**, including its original RAR or ZIP format, internal directories, filenames, XLS/XLSX workbooks, and accompanying documents. Do not extract and commit individual tables as replacements for the publisher archive.

Retain original release filenames where practical, for example `info-stat-06-2026.rar` and `info-stat-08-2026.zip`. The `MM-YYYY` token identifies the issue label in the publisher filename; do not assume it defines the reference period of every table inside. An amended or replaced issue must remain distinguishable through source version identity and Git history.

This is an `originals/`-only series. No parallel `scrolls/` directory or mandatory full-document AI conversion is required. Any later algorithm-readable tables should be emitted as separately traceable `flakes/` artifacts under appropriate economic-domain routes, with release, internal member, table, unit, period, classification, and geographic-perimeter provenance.

Do not silently harmonize regional boundaries, source classifications, periods, indicators, missing values, or file layouts across issues.
