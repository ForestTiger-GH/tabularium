# Originals

Selective archive of untouched, publisher-distributed primary-source files. Preserve source bytes exactly; a repository filename or location may be changed without rewriting the content.

## Route

- [`russia/`](russia/) — archived Russian primary-source files.

AI-readable publications belong in [`scrolls/`](../scrolls/); algorithm-readable series artifacts belong in [`flakes/`](../flakes/). An original is retained only when it provides material preservation value: it is not a mandatory pipeline step. Do not create unused parallel routes.
