# MADAR Workspace

Internal engineering workspace for developing and maintaining Tabularium.

Current scope is intentionally small: bounded research, repository schemas and machine-readable helpers, AI working rules, maintenance/development guidance, and temporary hands-on implementation experiments.

This workspace is outside the authoritative public-source corpus under `scrolls/`. Research and work material does not become a repository rule, schema, accepted observation, or current product state merely by being stored here.

## Route

- [`_arrivals/`](_arrivals/) — temporary intake staging for newly added source files awaiting identification, naming, conversion where required, and routing into the authoritative corpus.
- [`research/`](research/) — bounded studies and exploratory engineering work.
- [`work/`](work/) — temporary hands-on development, pilots, queues, candidates, checkpoints, and other non-authoritative working material.

Use the current MADARAII `FOUNDATION`, `MADARAII-01`, and `MADARAII-02` as the organizational basis. Add physical structure only when a real responsibility requires it.
