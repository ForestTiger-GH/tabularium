# MADAR Workspace

Internal engineering workspace for developing and maintaining Tabularium.

Current scope is intentionally small: bounded research, repository schemas and machine-readable helpers, AI working rules, and maintenance/development guidance.

This workspace is outside the public-source corpus under `russia/`. Research material does not become a repository rule, schema, or current product state merely by being stored here.
