# Work

Temporary, non-authoritative engineering work for Tabularium.

This directory may contain hands-on pilots, candidate records, queues, checkpoints, scratch mappings, and other development artifacts. Nothing here is part of the authoritative source corpus under `scrolls/`, and nothing here becomes an accepted Tabularium schema, observation, binding, method, or product contract merely by existing here.

Rules:

1. Never modify a source artifact in order to make a work result fit.
2. Freeze every tested source by path plus Git blob SHA or a stronger content hash when available.
3. Mark partial extraction and sampled coverage explicitly.
4. Keep reported extraction separate from mappings, derivations, and analytical conclusions.
5. Prefer small, disposable experiments over speculative infrastructure.
6. A successful pilot must be promoted explicitly into current repository contracts; do not treat `work/` as production state.
