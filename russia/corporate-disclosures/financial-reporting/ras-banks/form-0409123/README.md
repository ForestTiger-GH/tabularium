# Form 0409123

Bank of Russia form 0409123: Calculation of Own Funds (Capital) (Basel III).

This directory contains a remote-source bridge, not a local copy of the monthly regulatory dataset.

Start from the Bank of Russia institution reporting index for availability. Use the CreditOrgInfo XML method for structured form data and the bulk DBF publication as a fallback, subject to the date-effective disclosure regime.
