# Rosstat

Primary machine-readable publications issued by the Federal State Statistics Service (Rosstat).

## Route

- [`social-economic-position-russia/`](social-economic-position-russia/) — Social and Economic Situation of Russia.
- [`short-term-economic-indicators/`](short-term-economic-indicators/) — Short-Term Economic Indicators of the Russian Federation.

Create one stable directory per publication series. Keep native machine-readable artifacts in their source format. Store PDF publications as complete source-faithful Markdown transcriptions. Use an issue directory only when one release contains multiple related artifacts.
